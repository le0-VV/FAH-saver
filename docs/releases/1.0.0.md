# FAH Saver 1.0.0

FAH Saver displays a Folding@home work unit as a screensaver on macOS and Windows.
It connects to a local client or a client on a private LAN or Tailscale network.
This is an independent project, not an official Folding@home product.

## Install

On an Apple-silicon Mac, install with Homebrew:

```sh
brew install --cask le0-VV/fah-saver/fah-saver
```

Select FAH Saver in Screen Saver settings and set the FAH source in Options.
Remove a previous manually installed copy before switching to Homebrew. The cask
uses the per-user Screen Savers folder. Keep your existing preferences.

For a manual Mac installation, download `FAHSaver-macos-arm64-v1.0.0.zip` and open
`FAHSaver.saver`. Intel Macs are not supported by this release.

On Windows x64, download and run `FAHSaver-Setup.exe`. Setup installs the
files in a permanent per-user location, registers **FAH Saver**, and adds an entry
to Windows Apps for removal. You can delete the downloaded installer. Run a newer
installer to update; preferences and the cached model are preserved.

Use `ws://127.0.0.1:7396/api/websocket` for a client on the same machine. For a
remote client, see the [private LAN and Tailscale setup](../direct-access.md).

## Included

- Native Metal rendering on macOS and Vulkan rendering on Windows.
- A default limit of 24 fps, configurable from 1 to 240 fps.
- Follow Latest playback, or looping through the available WU snapshots.
- A configurable snapshot interval, initially 1 second, with no imposed upper
  limit. The minimum is 0.05 seconds.
- Space-filling, ball-and-stick and sticks styles, with fixed, cycling or random
  style selection.
- Light, dark and plain background choices.
- A cached latest complete model for immediate startup and offline display.
- GPL-3.0-or-later source, build instructions and third-party notices.

FAH's 25 MB visualisation cache still limits the available snapshot history.
There is no companion collector or account-based remote relay.

## Known limits

- The macOS legacy screensaver host can retain extra or inactive renderers after
  a Settings preview. Continued GPU use and substantial memory use remain
  unresolved. This release does not claim an optimal memory footprint.
- Windows renders one surface across the virtual desktop. It does not provide
  independent scenes per display.
- The macOS bundle is ad hoc signed and is not notarised. The Windows installer
  is unsigned. Downloaded files can require platform trust approval.

See the [verification record](../verification.md) for test methods, measured
performance and remaining limits. Both downloads include licence notices. The
corresponding source, build and installation scripts are available at the
[v1.0.0 source tag](https://github.com/le0-VV/FAH-saver/tree/v1.0.0) and through
GitHub's automatic source archives. Manifests and checksums remain available in
the build's verification artefacts.

Publishing a stable GitHub release automatically updates the Homebrew cask to
the release-specific macOS archive URL and its verified SHA-256 hash.
